Oracle VBCS: 40+ apps for PennEngineering

Oracle Visual Builder Cloud Service (VBCS) is Oracle's low-code platform for web apps. It's built on Oracle JET, so you get enterprise-grade oj-* components, and it generates real HTML, JSON and JavaScript you can version and review. I've used it to give PennEngineering's teams fast, clean front ends over their JD Edwards data, delivering more than 40 production applications.

1

Connect

REST service connections defined from OpenAPI (openapi3.json) to JD Edwards Orchestrator endpoints and Spring Boot APIs, with SSO and secure authentication.

2

Model

Typed variables and data providers (e.g. ArrayDataProvider) feed tables, dropdowns and forms, so the UI reflects exactly what the ERP returns.

3

Build the page

Pages are HTML plus JSON with Oracle JET components: editable grids, filters, searchable selects, validations and responsive layouts.

4

Wire the logic

Action Chains (JavaScript) call the services, transform responses, handle errors and navigate between pages, keeping business logic out of the markup.

  • Consistent, reusable app structure across the whole portfolio of apps, so new apps start fast
  • Editable grids and dropdowns backed by live JD Edwards data through Orchestrator
  • Spring Boot services behind the UI where logic needs more than an orchestration
  • Deployed and secured on Oracle Cloud with SSO
